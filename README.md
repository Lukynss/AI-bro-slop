# Slopsum

A Lorem Ipsum generator for the empty, overconfident dialect of enterprise AI. It writes grammatically readable paragraphs of agentic business speak you can drop into a mockup. The sentences are confident. The meaning is not included.

Everything runs in the browser. There is no account, no API, and no database.

## Run it locally

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123).

The page loads with a sample already generated. Change the paragraph and sentence counts, then use Generate. Copy puts the paragraphs on the clipboard, separated by a blank line.

## Production build

```bash
npm run build
npm start
```

## Tests

```bash
npm test
```
